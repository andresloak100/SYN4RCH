# D-105 power: size and power of the primary decision on synthetic hypothalamic data

Generated by `python3 -I analysis/d105_benchmark.py power`. No hypothalamic count is read. The prediction is model D's frozen prediction for the 19 units; model A's frozen prediction enters the PASS condition r_D > max(r_A, 0). True profile T = rho * D's double-centred prediction + sqrt(1 - rho^2) * noise, double-centred, sd 0.85; rho is a mixing weight, and the realised r_unit of D against the noiseless T ('true r') is about 0.96 x rho. The noise is independent N(0, 1) entries or a Gaussian process over the 19 MERFISH centroids (length 0.25 / 0.5 / 1 / 2 mm, independent per target). Counts: 7 targets x (female, male); experiment totals uniform 25-150, then rescaled so the 14 experiments hold 958 neurons of the 19 units (the total given in the spec, as in protocol/p4_power.py); unit sizes 50.4 x lognormal(0, 0.6), shares proportional to size x exp(T + 0.35 experiment noise). Every dataset is scored exactly as `run` does: r_unit, within-strata permutation p with the frozen 10000 permutations (strata sizes [4, 3, 4, 4, 4]), the noise ceiling, the interval (1000 bootstrap draws here, 2000 in `run`) and the reading. 'p full' uses unrestricted row permutations (comparator only). 'CI covers mean r_D': share of datasets whose 95% interval contains the mean of r_D over that row's datasets (a calibration check at a fixed truth).

Size: the pass rates at rho = 0 should be at or below 0.025 (Monte Carlo SE 0.005 with 1000 datasets); the pass rule also needs r_D > max(r_A, 0), which can only lower them. With spatially smooth truths, compare the within-strata column with the unrestricted-permutation column. The max-T and A columns at rho = 0 are the sizes of those secondary tests at nominal 0.05 (A's p is not calibrated under smooth truths, since A is itself a smooth function of position; only r_A enters the decision).
Interval: r_D +/- t(0.975, 18) x sqrt(19/18) x bootstrap SD. Resampling units treats them as exchangeable, so the interval still undercovers somewhat when the truth is spatially smooth.
Readings are given for datasets that do not pass; a dataset that passes still has a reading computed, so the three reading columns describe the interval and ceiling rules on every dataset.
The ceiling is the between-sex reliability (Spearman-Brown) of the measured profile; the attainable r_D is about its square root.
Labelled neurons of the 19 units per synthetic dataset: 958 (spec-supplied total).
