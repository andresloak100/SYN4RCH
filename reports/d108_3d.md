# D-108 3D: letting a constrained search choose spatial relationships in a 3D brain

## Declared before any real-label run (2026-11-10 14:47:54; machine copy data/interim/d108_3d_declared.json)

**Question.** Assemble the brain in 3D from atlas data (each cell type's real cell cloud, fibre tracts, a voxel route graph), then let an algorithm choose which spatial relationships help predict Epi-retro-seq projection profiles on held-out divisions, on top of model D. The choice is constrained (Phase 1's open search over 66 terms overfit): at most 3 of 7 fixed feature families, chosen inside the training divisions only.

**Data.** Local only. Allen MERFISH cells (CCF, folded at the midline as d105), the CCF ontology, Allen 10x cluster means (F4 only, through D's frozen PCA), d105/d108 frozen embeddings and the M1 location module. Projection-derived anatomy is excluded: `data/raw/atlas/connectivity` is never opened; Epi-retro-seq is read only through `d105_benchmark.read_st2_training` (HY rows dropped on read; HY19 removed from every training source).

**Feature families** (one block each; tag M measured, I inferred with uncertainty; no P features):

| family | terms (pair = one coefficient; K = unit features x target encoding) | tag |
|---|---|---|
| F1 basic | -log centroid distance (distLm); unit centroid x target centroid | M |
| F2 cloud geometry | -log median and 5th-percentile distance of the unit's cells to the target region's cells; overlap (share within 0.2 mm); cloud shape (log spread, elongation, main-axis direction) x target centroid | M |
| F3 neighbourhood | composition of the 30 nearest atlas cells around the unit's cells (6 PCs of a brain-wide reference) x target centroid; similarity of that composition to the target region's composition | M |
| F4 compatibility | gene embedding (8 PCs) x target composition; unit embedding . target mean embedding (D's frame) | M |
| F5 corridor access | shared-tract score (sum over 14 tract structures of source access x target access, 0.3 mm); access to 6 tract systems x target centroid | I |
| F6 route cost | -log route cost through the voxel graph with tract voxels at cost 0.25 (sd over 0.1 / 0.5 stored); log(uniform geodesic / tract route) | I |
| F7 inferred placement | -log distance from gene-inferred location (M1) to target, averaged over 200 draws of its uncertainty; inferred location x target centroid | I |

**Models** (one weighted ridge, D's head, lambda fixed at 0.3 for all; scales label-free over the 27 sources' units, as Phase 1):

* D: gD32 x one-hot.
* D + basic: D + F1 (fixed).
* D + 3D-all: D + F1..F7 (fixed; the fixed candidate).
* D + 3D-search: D always kept; greedy forward selection of families by mean inner leave-one-division-out r_unit inside the outer training divisions; a family is added only if the inner score rises by >= 0.01; at most 3 families.

**Evaluation.** Nested leave-one-division-out over the 27 non-HY sources (d105 folds); r_unit per held-out division (d105 form); mean over the 7 divisions (mean7).

**Replicates (fixed now).** Shuffled-label null N0: 60 full nested runs (same seeds as Phase 1, so the same shuffled datasets). D-as-truth null N2: 60 full nested runs (Phase 1's datasets: beta 0.259, tau 0.35). Planted controls: 8 replicates each of (a) a route-cost rule (F6 route term, beta 0.582) and (b) a neighbourhood rule (F3 nb6 x target centroid, beta 1.206), each at true r 0.40, planted on the real counts as in Phase 1. 4 workers.

**Decision rules.**

* Paired tests vs D and vs D + basic: exact one-sided sign-flip over the 7 divisions; Monte Carlo sign-flip (200,000) over sources and over units (unit cosine).
* Consistency: improves in >= 5 of 7 divisions; survives dropping any one division (mean delta > 0 on each of the 7 six-division subsets).
* **Verdict vs D** for D + 3D-all and D + 3D-search: RELIABLE GAIN iff delta = mean7(model) - mean7(D) > 0 AND division sign-flip p < 0.05 AND p_N2 < 0.05 (the same model's delta on the 60 D-as-truth datasets; p = (1 + #null >= observed) / 61) AND improves in >= 5 of 7 AND survives drop-one. NO GAIN iff delta <= 0. ENCOURAGING, NOT RELIABLE iff delta > 0 and >= 5 of 7 but another condition fails. NOT SHOWN otherwise.
* **Verdict vs D + basic**: same, without the N2 condition.
* **A family is reliably chosen** iff selected in >= 4 of 7 outer folds AND that count is above the 95th percentile of the largest per-family count under N0.
* **Planted control**: recovered in a replicate iff its family is selected in >= 4 of 7 outer folds; the control passes iff recovered in >= 50% of replicates (must pass for a negative real result to be read as "no spatial signal" rather than "search cannot see it").
* p_N0 for each model's mean7 is reported.

**The user's prediction, scored after the run** (for each of D + 3D-all and D + 3D-search):

* P1 "D + 3D similar to D or slightly better": holds iff -0.02 <= delta <= +0.05.
* P2 "a reliable gain of 10-20% is likely": holds iff the verdict vs D is RELIABLE GAIN and delta / mean7(D) is between 0.10 and 0.20.
* P3 "encouraging if it improves in 5-6 of 7 divisions": holds iff it improves in 5 or 6 of 7.

**Development disclosures.** No real-label model was fitted during development. Timing pilot on shuffled labels (N0 replicate 999): 7 s wall, 28 s summed fold CPU for one full nested run (all four models). Check: D on Phase 1's shuffled replicate 0 reproduces Phase 1's per-fold r exactly (max difference 0). Planted betas were calibrated by the signal-only true r, which uses the real counts only as the base shares (as Phase 1); no model was scored on real labels. The N2 beta is Phase 1's (not recalibrated).

## Results (runs 2026-11-10 14:48 to 14:54; nothing changed after the declaration)

**In short.** Building the brain in 3D worked, and the planted controls show the search can find a real spatial rule when one is there. On the real data, though, none of the 3D models beat model D. D scores +0.228 on held-out divisions. D + 3D-search scores +0.168: it is never better than D in any division, ties D in 3 and is worse in 4. D + 3D-all scores +0.071, and D + basic scores +0.189. All verdicts are **NO GAIN**. The user's prediction was not borne out: the 3D models were neither similar to D nor slightly better, so none of the three parts holds.

### The 3D brain (saved whatever the result)

* `data/interim/d108_3d_brain.npz` + `d108_3d_brain_card.json` (+ `d108_3d_cells.npz`, compact cell table; `d108_3d_brain_views.png`). API in `analysis/d108_3dbrain.py`: `load()`, `cloud_cells(B, subclass, region)`, `unit_features(B, cloud, subclass, targets)`, `lhat_features(...)`.
* Space: CCFv3 in mm, folded at z = 5.7 mm. Voxel grid of 200 um, 65 x 39 x 27. 41,055 voxels are in the brain (one connected component). 10,542 of them (26%) hold no cell of their own and were labelled from the nearest cells within 0.45 mm (in the same or neighbouring sections); they are flagged. The atlas has 53 sections spaced about 0.2 mm apart, with gaps of up to 0.78 mm at the front.
* Fibre tracts were checked against the local data. There are 320,454 MERFISH cells labelled `fiber tracts`. Every tract label is a descendant of 'fiber tracts' in the local ontology: 6 systems, 20 structures and 63 substructures, with 0 mismatches. These labels give 3,940 tract voxels in 45 connected pieces; the largest have 2,756 and 910 voxels. By system: cm 1,532, lfbs 883, cbf 733, mfbs 411, scwm 127, eps 74, plus 180 labelled 'fiber tracts-unassigned' (total 3,940). 1,151 of the tract voxels hold no cell of their own and were labelled from nearby cells (as above). Only 14 tract structures have at least 20 voxels and are used as corridors (In, cc, arb, mfbc, cbp, cst, Vn, VIIIn, IIn, lfbst, mfsbshy, drt, rust, tsp). Small tracts (for example mfb proper, fx, sm, st) are covered only through their parent structures. **Supported:** a tract occupancy map and a voxel route graph at 200 um, which is enough for families F5 and F6. **Not supported:** individual axon routes. Tracts are treated as candidate corridors only. No annotation volume was downloaded and none was needed. A finer route graph would need the CCF annotation volume (for example `http://download.alleninstitute.org/informatics-archive/current-release/mouse_ccf/annotation/ccf_2017/annotation_25.nrrd`; I did not check its size). Downloading it needs the user's approval.
* The meshes in `data/raw/atlas/meshes` are the root plus 19 hypothalamic structures. There are no tract meshes, so they were not used.
* Route fields: Dijkstra over the 26-neighbour voxel graph, from each of the 24 target regions, under 4 cost settings: uniform (a geodesic that stays inside the brain), and tract cost 0.25 / 0.1 / 0.5.
* Units: 206 real cell clouds, built with d105's own selection of cells. 187 come from the non-HY sources (176 at parcel level, 8 at division level, 3 at whole-brain level). The other 19 are the HY test subclasses in HY, built from atlas cells only, so the features are ready for the unseen region. Each centroid reproduces d108_prep, and each target centroid reproduces Phase 1.
* Families: all 7 families could be built (F1 to F7; tags as declared). No feature is derived from projection data.

### Nulls

* **N0, shuffled labels (60 full nested runs):** mean7 averaged -0.005 (D), -0.005 (basic), -0.004 (3D-all) and +0.004 (3D-search). The 95th percentiles were +0.117, +0.125, +0.125 and +0.105. Real p_N0: D 0.033, basic 0.033, 3D-search 0.033, 3D-all 0.148. So 3D-all on real labels cannot be told apart from 3D-all on shuffled labels. On shuffled data the search added at least one family in 94% of folds. The largest per-family count across 7 folds has a 95th percentile of 7, so no family could ever pass the "reliably chosen" rule.
* **N2, D as the truth (60 runs):** D mean7 averaged +0.219. The mean deltas were basic -0.021 (95th percentile +0.007), 3D-all -0.075 (95th percentile -0.014; delta > 0 in 1.7% of runs) and 3D-search -0.031 (95th percentile +0.022; delta > 0 in 15%). This is the price of adding families when D is right. The real deltas are below these distributions: p_N2 is 0.836 (basic), 0.984 (3D-all) and 0.836 (3D-search).

### Planted controls (8 replicates each, true r 0.40)

| planted rule | family selected (folds of 7, per replicate) | recovered | D | D + basic | D + 3D-all | D + 3D-search | oracle (true term alone) |
|---|---|---|---|---|---|---|---|
| route cost (F6) | 7 in every replicate | 8 of 8 | +0.182 | +0.246 | +0.254 | **+0.319** (> D in 8 of 8, p 0.004) | +0.375 |
| neighbourhood x target (F3) | 6 in every replicate | 8 of 8 | +0.219 | +0.173 | +0.164 | +0.204 (p vs D 0.93) | +0.209 |

Both controls pass the declared rule (recovered in 100% of replicates, against a bar of 50%). So the search can see a route rule or a neighbourhood rule and pick the right family. **But the two controls show different things.** "True r 0.40" was set as the signal-only r, not as a gain over D. For the route rule the planted term adds a lot beyond D (oracle +0.375 vs D +0.182), and the search turns it into a clear gain (+0.319, p 0.004). For the neighbourhood rule the true term alone (+0.209) already scores below D (+0.219): the planted signal overlaps what D explains. That control therefore shows only that the search **finds** the family, not that a gain over D could be detected. The only evidence that this pipeline can detect a real gain over D comes from the route rule. (Future controls should set strength by the gain over D and add a power rule on that gain.)

### Families chosen per fold, and why

* Selected: F4 compatibility in 3 of 7 folds, F7 inferred placement in 2, F3 neighbourhood in 1, F1 basic in 1. F2 cloud geometry, F5 corridor and F6 route were never chosen. The search kept D alone in amygdala-pallidum, hindbrain and olfactory.
* **Flaw in the declared "reliably chosen" rule.** It compares each family's count with the 95th percentile of the largest count over all 7 families under N0, which is 7 of 7; no family could ever pass. A fairer, family-specific comparison (post hoc, not declared, so it cannot change any verdict): under N0 the per-family chance of being chosen in >= 4 of 7 folds is 0.07 (F6) to 0.27 (F5), per-family 95th percentiles are 5-6; under N2 (D true) F4 reaches >= 4 in 50% of runs. On real labels no family reaches 4 of 7 (F4 is highest at 3; N0 chance of >= 3 for F4 is 0.38, N2 0.58). So no family is reliably chosen under either rule. A future run should declare a family-specific null percentile. Numbers in `data/interim/d108_3d_posthoc.log`.
* Optimism: in the folds where families were added, the inner score rose from D's 0.11-0.18 to 0.20-0.34. Every one of those folds then lost on the held-out division (by 0.04 to 0.21). This is the same overfitting as in Phase 1, on a smaller scale. Constraining the search to families limited the damage (+0.168 against Phase 1's -0.062) but did not turn it into a gain.
* Ablation in the real folds (outer r lost when a family is dropped; negative means the family hurt): F7 -0.118 (hippocampal) and -0.060 (isocortex); F4 +0.081 (hippocampal), -0.025 (midbrain) and -0.209 (thalamus); F3 +0.026 (isocortex); F1 +0.001 (midbrain).
* Descriptive only (not used for any decision; selected after seeing held-out results, so optimistic): D plus one family, fixed, gives mean7 F6 route +0.219, F4 +0.208, F5 +0.204, F1 +0.189, F3 +0.167, F7 +0.152 and F2 +0.145. None beats D on average, and each beats D in at most 3 of 7 divisions. F6 route comes closest (+0.219 vs D's +0.228).
* D + 3D-all overfits even inside the training divisions: its inner score is below D's in 6 of 7 folds (for example 0.075 vs 0.202 in amygdala-pallidum; midbrain 0.193 vs 0.171 is the exception).

### What this means

From local atlas data, the 3D brain could be assembled honestly: real cell clouds, a tract occupancy map, a route graph, and features for the unseen hypothalamic units. It is saved for reuse. When a spatial rule is planted, the constrained search finds the right family every time; for the route rule, which adds signal beyond D, it also turns that into a clear gain over D (the neighbourhood control could not test this). On the real projections, no spatial family adds to model D on held-out divisions. Most families do not even match the simpler D + basic, and D + basic is itself slightly below D. The algorithm's choices inside the training divisions again do not carry over. The signal that transfers across divisions is still what D captures from gene expression. Spatial relationships measured from the atlas (distance, cloud shape, neighbourhood, tract access, route cost) carry nothing extra that survives a new division with 187 training units. The one weak lead is route cost (F6). Added alone to D it comes within 0.01 of D's mean7 (+0.219 vs +0.228), and it carries the planted signal well. It would be worth retesting only with more training units or the hypothalamic data, not by searching harder here.

### Disclosures and limits

* Every unit node and pairwise scale is normalised over all 27 sources' units, held-out division included. This uses no labels and is the same practice as Phase 1. **Checked after the run** (not declared): recomputing pair scales, unit scales and new-node normalisation from the outer-training sources only gives D +0.228, basic +0.188, 3D-all +0.069, 3D-search +0.169, with identical families chosen in every fold. The verdicts do not change (`data/interim/d108_3d_posthoc.log`).
* An independent audit rebuilt the 3D brain bit for bit (all 60 arrays), re-ran real labels, N0 reps 0 and 37, N2 rep 0 and planted route rep 0 with max difference 0, and recomputed every statistic above. Exploratory audit check (not declared): choosing lambda by nested inner LODO from {0.1, 0.3, 1, 3, 10} makes 3D-all worse (+0.024 vs D +0.216 on that run), so the fixed lambda 0.3 is not what held it back.
* **N0 shuffle is weak.** Labels are permuted among units within a source; with 2-3 units in some sources, on average 14.5% of units keep their own label. One shuffled run (replicate 45) gives D +0.240, above the real +0.228, so p_N0 is conservative (floor 2/61 = 0.033). Inherited from Phase 1; no verdict uses p_N0. A future run should use derangements or permute across sources within a division.
* **Real labels in nulls and controls.** The planted datasets add signal on top of the real counts, and the N2 truth is D fitted in-sample to the real labels. Both ran after the declaration with the code frozen, so no choice was tuned on them, but "no real labels before the real run" holds only for fitting models to unmodified labels.
* **Evidence for the declaration is file times only.** `d108_3d.py` (which holds the verdict rules and P1-P3 thresholds) was last modified 14:46:49, the pilot ran 14:47:49, `d108_3d_declared.json` was written 14:47:54, the runs log starts 14:48:22, the real-run marker was written 14:54:04. `declared.json` does not itself contain the rule text or a code hash, nothing was committed before the run, and this report was edited after the run (results added; this disclosure section revised at finalisation), so its pre-run state cannot be shown. SHA-256 of the files as finalised are listed under Files. A future run should hash the code and rule text into the declaration or commit first.
* **Geometry limits.** The brain is folded onto one hemisphere, so commissural corridors (cc, ac) and crossing routes cannot be represented. The 19 HY test clouds are all division level, while 176 of the 187 training units are parcel level, so their cloud features differ in kind. The 24 targets are the training targets.
* F4 does not depend on the 3D layout (target composition and gene embeddings). It is included because the family list specified it.
* F5 uses only tract structures with at least 20 voxels. Corridor and route features assume that tract voxels are cheap paths; none of this is axon-route evidence. The route cost has an uncertainty from the spread over cost factors (stored per unit and target, as `route_sd`), but the models used only the central value.
* Runtime (4 workers): real run 27 s of fold CPU; N0 602 s; N2 535 s; planted 168 s; whole chain 6 minutes.
